# LINE Weekly Brief Format

Format-only asset. Python generates the text; downstream Java owns LINE delivery and webhook behavior.

## Weekly Brief Shape

1. 市場主線
2. 跨資產訊號
3. 台股傳導
4. AI 與科技鏈觀察
5. 原物料與匯率
6. 下週觀察重點
7. 反證與觀察限制

## Daily Market Analysis Override

Daily `market_analysis` uses this visible order:

`今日一句話` -> `三個檢查點` -> `市場押注與預期差` -> `國際消息到台股的傳導` -> `看錯的條件` -> `備註`

- `今日一句話` 一句話說清楚市場現在交易的是什麼、台股偏多/偏空/中性，以及最大不確定性。
- `三個檢查點` 必須剛好三點，每點連接：來源事實 -> 市場機制 -> 為何現在重要。
- `市場押注與預期差` 說明哪些預期已經反映、哪些仍可能重估。
- `國際消息到台股的傳導` 只能以 NVIDIA、台積電、Magnificent Seven / 美股七巨頭等權值股作傳導例子，不做進出場建議。
- 可試用觸發型節奏：`今日一句話` 可用「結論先講」開頭，`市場押注與預期差` 可放「先看區間邊界」，`看錯的條件` 可放「現在只看 N 件事」；N 依證據決定，不限兩件，且所有點位只能當觀察邊界。
- 不得新增 `台股配置` 或 `今日個股觀察`。
- 不得寫 `開多`、`開空`、`止盈`、`止損`、`入場區間` 或下單型文字。
- 若資料過期或不足，降低信心並改寫在備註；不要在可見文字寫「資料不足」、「缺漏」、「需等待更新」或內部流程原因。

## Format Rules

- 短段落，避免牆狀文字。
- 數據集中用條列，先講市場意義，再放數字。
- 不顯示內部欄位、代碼、資料表名、模型名、任務名或 API/guard 名稱。
- 不顯示任何 snake_case 欄位、排程代碼、來源代碼或稽核欄位。
- LINE 推播摘要只放一句話與連結，不塞完整文章。
